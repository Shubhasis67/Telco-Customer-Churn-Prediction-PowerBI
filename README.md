## 📊 Buisness Insights & Key Findings

### 🔍 Core Discoveries
* **Customer Churn Dynamics:** Customer churn varies significantly across contract types, with shorter-term customers requiring particular attention.
* **Strategic Segmentation:** Tenure is an important segmentation variable, allowing the buisness to identify early-stage customers who may need stronger engagement.

### 💡Data-Driven Solution
* **Predictive Risk Modeling:** The Logistic Regression model converts customer characteristics into a churn probability, allowing customers to be prioritized based on estimated risk.
* **Executive Decision Making:** The Power BI dashboard enables management to filter high-risk customers by contract, tenure, service type, and payment method.
